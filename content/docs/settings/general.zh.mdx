**General** 标签页控制侧边栏与智能体的行为,并让你塑造智能体的人设。

## 侧边栏与智能体(Sidebar & Agent)

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| **Sidebar default** | 默认(记住上次状态)/ 自动打开 / 仅手动 | 侧边栏是否自动打开 |
| **Agent execution** | 四个档位(见下) | 智能体在不询问的情况下可以做多少事 |
| **Data storage** | 路径 | 制品与会话数据的存放位置(如 `~/.config/nevoflux/`) |

这些设置即时保存。

## Agent execution 权限档位

**v0.3.13** 新增:**Agent execution** 不再是"确认 / 自动"的二选一开关,而是一个四级
阶梯。每一档都自动批准下一档的全部内容,再加上一类新的工具。某一档**未**覆盖的操作
仍会弹出[权限提示](/zh/docs/features#权限人类在环)。

| 档位 | 新增自动批准 | 仍然会询问 |
| --- | --- | --- |
| **Read-only** *(默认)* | 读取页面、导航、等待;网络搜索与抓取;知识库读取;思考、制定计划,以及告知你信息 | 其余全部 |
| **Browser auto** | + 浏览器交互:点击、输入、填表、滚动、按键 | 本地文件、shell,以及其余全部 |
| **Browser auto + reads** | + 本地文件读取(`read_file`、`list_files`、`glob`、`grep`) | 文件写入、shell,以及其余全部 |
| **Full auto** | 全部 —— 不再确认 | 无 |

有几点容易猜错:

- **导航算作只读。** 打开一个 URL 属于最低档;而与载入后的页面**交互**不属于。
- **`browser_eval_js` 不算浏览器交互。** 在页面中执行 JavaScript 与 shell、文件写入同属
  最高类别,因此需要 **Full auto** —— 它能做的事远多于一次点击。
- **切换标签页属于浏览器交互**(自 v0.3.16 起):`browser_activate_tab` 需要
  **Browser auto**;而读取控制台或已记录的网络请求
  ([`browser_console_messages`、`browser_network_requests`](/zh/docs/features/browser-automation))
  属于只读。无论其他权限如何,创建定时任务都需要 **Full auto** —— 见
  [定时任务](/zh/docs/features/scheduling)。

分类器无法识别的工具 —— 包括新工具、MCP 工具和第三方工具 —— 一律归入同一个最高风险
类别,因此在 **Full auto** 以下的档位,未知工具永远不会被自动批准。

> **从 v0.3.13 之前的版本升级?** 旧的 **Auto-execute(自动执行)**选项是一个从未真正
> 生效的桩实现。它**不会**被迁移为 **Full auto**,而是重置为 **Read-only** —— 因为在
> 升级过程中悄悄授予完整权限,比让你重新选一次更糟。更新后请检查这项设置。

该档位同时限定了会话能**创建**什么:见
[循环与执行档位](/zh/docs/features/automation#循环周期性任务)。

## 语音模型与语音

v0.3.15 新增的两个分组,用于设置与智能体对话、并听它回答。一切都在本机运行;工作原理见
[语音](/zh/docs/features/voice)。

**Speech Models** 按需下载本地语音模型。每一行显示大小和状态,并提供 **Download**、
**Cancel** 和 **Resume**(中断的下载会从断点继续):

| 行 | 提供的能力 |
| --- | --- |
| **Speech input** | 识别你说的话。语音输入需要它(约 240 MB)。 |
| **Spoken replies** | 朗读回答——仅英文,一个小型兜底音色(约 120 MB)。 |
| **Chinese replies** | 中文和英文音色;可替代上一行(约 375 MB)。 |
| **Natural voice** | MOSS-TTS-Nano:中文及另外 19 种语言,音质明显更好,但体积大(约 717 MB)。 |

**Voice** 控制朗读内容:

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| *(引擎说明行)* | — | 由哪个引擎朗读(MOSS 或 Kokoro)及原因;**Re-measure** 可清除"太慢"的判定 |
| **Voice** | — | 使用的音色,来自实际负责朗读的引擎 |
| **Speak replies** | 关 | 语音输入开启时朗读回答。关闭时回答只以文字显示——语音听写照常可用 |
| **Use GPU when it helps** | 开 | 允许语音尝试 GPU,仅当它比 CPU 快时才保留。关闭则始终使用 CPU。下次语音启动时生效 |
| **Voice view** | 关 | 语音开启时用波形取代消息气泡;回答照常生成、保存、可搜索 |

## 人设("灵魂")文件

五个 Markdown 卡片让你塑造智能体是谁、它对你和你的环境了解什么。点击
**Save All Settings** 时,每个卡片会保存到你配置目录下的一个文件:

| 卡片 | 文件 | 用途 |
| --- | --- | --- |
| **Identity** | `IDENTITY.md` | 智能体的名字、性格、气质(以及**头像**) |
| **Soul** | `SOUL.md` | 核心价值观与行为准则 |
| **User** | `USER.md` | 关于*你*的信息(姓名、称谓、时区、背景) |
| **Tools** | `TOOLS.md` | 你的环境(SSH 主机、设备、TTS 偏好) |
| **Agents Runtime** | `AGENTS.md` | 运行时指令、记忆规则、安全协议 |

*示例:* 在 **User** 中粘贴一段简短自我介绍和你的时区,然后 **Save All Settings** ——
智能体会据此为你定制回答。在 **Identity** 中设定名字和性格,可让助手拥有一致的口吻。

> 这些文件还参与 NevoFlux 的[自学习](/zh/docs/features/automation)系统,随时间推移
> 它可能会提议对其进行更新。

## 每个 Space 的人设(Space Souls)

v0.3.12 新增:你可以在 **Space Souls** 设置中,为**每个浏览器 Space 单独指定助手人设**
—— 一个 Space 用 "research" 灵魂,另一个用 "engineer" 灵魂。一个灵魂、它的私有记忆,以及
该 Space 的 cookie 隔离都共用同一个键。关于其概念与使用场景,见
[功能 → Space Souls](/zh/docs/features/space-souls)。

绑定保存在配置目录下的 `space_souls.toml` 中,把 Space 的容器 id 映射到某个灵魂(角色)
slug:

```toml
# ~/.config/nevoflux/space_souls.toml
[bindings]
"firefox-container-1" = "research"
"firefox-container-2" = "engineer"
```

若某个 Space 未绑定(或该文件不存在),助手的行为与上面单一的全局人设完全一致。
